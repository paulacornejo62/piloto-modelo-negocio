## PARTE 0 — Dos formas de mirar el modelo de negocio (leer primero)

### Lo que enseña el curso CORFO Conecta (y lo que pide CORFO)

- **Lienzo Canvas** (9 bloques): segmentos de cliente · propuesta de valor · canales · relación con clientes · fuentes de ingreso · recursos clave · actividades clave · asociaciones clave · estructura de costos.
- **Go-to-Market**: cliente objetivo (los primeros clientes reales), estrategia de entrada, pricing. El I+D exitoso no termina cuando funciona, sino **cuando alguien paga por él**.
- **Curva de valor** (Blue Ocean): costo · mercado · atributos (factores competitivos) → contra qué compite el negocio y qué atributos sube / baja / crea.
- **Pricing — 3 formas de fijar el precio:**
  1. **Comparación con el mercado** (lo que cobran otros).
  2. **Margen sobre costo** (costo + un margen).
  3. **Valor capturable** (lo máximo que el cliente estaría dispuesto a pagar por el beneficio).
- **Indicadores de tracción**: cómo el cliente medirá el éxito — N° de clientes, monto de ventas o financiamiento apalancado, % de cumplimiento de hitos, cartas de interés / contratos, renovaciones. Son de **conteo / cualitativos**, no ratios financieros.

### Lo que puse en el motor (a revisar con la jefa)

| Del motor | Qué es | Recomendación |
|---|---|---|
| Tamaño de mercado **TAM / SAM / SOM** | Mercado total / servible / obtenible en el horizonte | **Mantener** — CORFO lo pide en "mercado objetivo". |
| **Margen de contribución** | Precio de venta − costo variable de esa unidad. Lo que queda de cada venta para pagar los costos fijos. Si es negativo, cada venta te hace perder plata. | **Mantener** — intuitivo y relevante. |
| **Punto de equilibrio** (break-even) | Cuántas unidades hay que vender para que ingresos = costos totales. Antes: pérdida; después: ganancia. | **Mantener.** |
| Proyección de ventas por escenario | Ingresos/costos/resultado a 3–5 años, pesimista/base/optimista | **Mantener, simplificada.** |
| **CAC** (costo de adquisición de cliente) | Lo que gastas en marketing + ventas para conseguir un cliente, ÷ clientes conseguidos | **Opcional** — solo si aplica. |
| **LTV** (lifetime value) | Plata total que deja un cliente en toda su relación contigo (margen × duración) | **Opcional.** |
| **LTV / CAC** | Cuántas veces recuperas lo que costó traer al cliente (regla de dedo startup: ≥ 3) | **Opcional — solo modelos de suscripción / recurrentes.** |
| **Payback de CAC** | En cuántos meses recuperas lo gastado en traer al cliente | **Opcional.** |

**En una frase:** el motor debería centrarse en **(a) completitud y coherencia del Canvas, (b) tamaño de mercado, (c) dos chequeos económicos simples — margen de contribución > 0 y punto de equilibrio alcanzable dentro del SOM —, (d) proyección de ventas.** LTV/CAC/payback quedan como capa opcional para negocios recurrentes.

## PARTE 2 — Reunión con José Pablo (mañana): flujo general y nº de reuniones

**Objetivo:** encajar el modelo de negocio en el proceso general de postular un subsidio (~1 mes) y acordar el nº de reuniones con el cliente.

**Duración:** 45–60 min. **Llevas:** este documento (Partes 0 y 1) + el diagrama del flujo.

### Encaje en el mes de postulación

| Semana | Modelo de negocio (piloto) | En paralelo (GT) |
|---|---|---|
| 1 | **R#1** (perfil comercial + solución) · se manda al cliente la **tarea de datos** (precios, costos fijos/variables, BOM, pipeline, estados financieros) · arranca la investigación de mercado | Formulación técnica: alcance, objetivos, estado del arte |
| 2 | Investigación de mercado + QA de veracidad · **R#2** (llenar el resto del lienzo) | Metodología, plan de trabajo, presupuesto |
| 3 | Construir el modelo (Canvas + economía simple + proyección) · revisión · si faltan números, **validación corta con el cliente** | Capacidades, equipo, GID |
| 4 | Redacción de las secciones de mercado / modelo / escalamiento · **entrega a GT** | Integración, revisión final, envío |

### Posición a defender

**2 reuniones con el cliente + 1 tarea de datos + (si hace falta) 1 validación corta de números.** Es suficiente para llenar el lienzo Canvas y dimensionar el mercado, salvo:
- **Consolida y Expande**: su Etapa 2 es casi puro plan de negocios (estrategia, escalabilidad, proyección financiera, inversión/retorno) → presupuestar **3 reuniones** para este fondo.
- Cliente que llega sin ningún dato comercial → la tarea de datos post-R#1 no alcanza; se necesita una sesión extra de levantamiento.

### Puntos frágiles (llevarlos identificados)

1. **Estructura de costos.** Fijo/variable, BOM, costo unitario. En hardware/deep tech el cliente rara vez lo tiene ordenado → depende de la tarea de datos.
2. **Validación de los números.** La proyección de ventas y el impacto (ventas incrementales, empleos) se arman sin cliente → necesitan un OK del cliente antes de cerrar. Hoy eso solo existe vía la compuerta DEVOLVER; ¿lo formalizamos como touchpoint corto?
3. **Pricing.** R#2 pregunta cómo se fija el precio, pero si el cliente no hizo pilotos ni cotizaciones, el precio es un supuesto.
4. **Asimetría R#1 / R#2.** Hoy R#1 es liviana y R#2 concentra casi todo el lienzo. Alternativa: llevar segmentos + propuesta de valor + pricing a R#1, y usar R#2 para canales/costos/actividades + validación.

- La empresa: razón social, tamaño, antigüedad, contacto.

- **Cliente objetivo / Segmentos** (grueso): a quién le vende hoy, cuántos clientes, ventas actuales.

- → Todo verificado cifra por cifra (año y geografía) por un QA independiente.

- **Fuentes de ingreso + Pricing**: qué se cobra, cómo (único / recurrente), y **cómo se fija el precio** (comparación con mercado / margen sobre costo / valor capturable).
- **Estructura de costos**: fijos y variables; ¿economía de escala o de alcance?
- **Recursos clave · Actividades clave · Asociaciones clave**.
- **Prueba y aprendizaje**: qué se valida en la primera fase.
- **Indicadores de tracción**: cómo el cliente medirá el éxito.
- Capacidad de ejecución: quién decide, qué le falta a la empresa.
- Lista de supuestos, cada uno marcado confirmado / por confirmar.

**Construcción del modelo + revisión** (sin cliente)
