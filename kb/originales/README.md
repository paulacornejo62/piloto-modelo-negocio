# Originales (documentos de mercado en PDF/HTML)

Aquí van los **documentos originales** descargados de las fuentes de la KB (informes,
memorias, notas de prensa). Cada ficha (`kb/fichas/<sector>/<id>.md`) referencia su original
por `id`.

> **Manejo por definir**: (a) **local** en esta carpeta (gitignoreados, como las fuentes
> pesadas), o (b) **referencia a Drive** (sin duplicar). Mientras tanto, esta carpeta queda
> como lugar definido pero el manejo no está implementado.
